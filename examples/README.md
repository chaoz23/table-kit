# examples

- **`demo_session.py`** — a whole synthetic seventy-minute session and its
  report. No config, no network. Start here; it is the fastest way to see what
  the instrumentation actually produces.
- **`example-module/spine.json`** — a module spine for the story lane, showing
  a hard gate, a soft gate, and two endings.

The demo session is deliberately imperfect. It contains an agent seat cued
without its literal mention, a seat left unaddressed for most of an hour, a
called roll nobody consumed, and a pacing complaint from two different players.
A demo where everything went well would not show you anything.
